# Tab Bar Icons

Place PNG icon files here (40x40px recommended) for the tab bar:

- home.png / home-active.png
- orders.png / orders-active.png
- profile.png / profile-active.png

You can use any icon set (e.g., Iconfont, Feather Icons) and convert them to PNG.
Until you have real icons, you can use base64 encoded mini PNG or use a CDN URL.

Alternatively, set icon paths in app.config.ts to remote URLs like:
  iconPath: 'https://your-cdn.com/icons/home.png'
